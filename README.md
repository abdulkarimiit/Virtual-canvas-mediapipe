
# Virtual Canvas using MediaPipe & OpenCV

A computer vision application that lets you write, draw, and erase on a virtual canvas in real time using hand gestures tracked via MediaPipe and OpenCV.

---

## 🚀 Features

* **Air Writing:** Draw seamlessly using your index finger.
* **Gesture Controls:** Easily switch between writing and erasing modes using intuitive hand gestures.
* **Real-time Hand Tracking:** Fast and precise hand landmark tracking powered by MediaPipe.

---

## ✋ How to Use & Gesture Controls

| Action | Hand Gesture |
| :--- | :--- |
| **Writing / Drawing** | Extend your **index finger** such that its tip is higher than your **middle finger tip** and **thumb tip**. |
| **Erasing** | **Curl all your fingers** into a fist or closed palm. |
